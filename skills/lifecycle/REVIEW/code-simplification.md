## 概述

简化代码使其更容易理解和维护，但不改变行为。

## 何时使用

- 函数超过 30 行
- 嵌套超过 3 层
- 有重复代码
- 条件表达式过于复杂
- 用户说"这段代码太复杂了"

## 简化策略

1. **嵌套简化** — 提前 return 减少嵌套
2. **长函数分解** — 提取有意义的子函数
3. **条件简化** — 复杂 if/else 用策略模式或查表
4. **消除重复** — DRY，但不过度抽象
5. **数据结构简化** — 用合适的数据结构简化逻辑

## 流程

1. 为要简化的代码写测试（保障行为不变）
2. 做一次简化
3. 运行测试确认行为不变
4. 重复

## 红旗信号

- "重构完一起测试" — 每次改完都要测试
- "这段代码太乱了我全重写" — 增量式，不是一次性重写

## 验证

- [ ] 简化后测试全部通过
- [ ] 行为不变（输出相同输入时相同）
- [ ] 没有降低代码可读性
